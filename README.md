# Terragrunt Atlantis Config

> [!IMPORTANT]
> This repository is no longer maintained.
> Development continues at [dbccompany/terragrunt-atlantis-config](https://github.com/dbccompany/terragrunt-atlantis-config).

Find current documentation and releases in the new repository.
Please open new issues and pull requests there.

## Switching to the maintained version

The Go module path is now `github.com/dbccompany/terragrunt-atlantis-config`:

```bash
go install github.com/dbccompany/terragrunt-atlantis-config@latest
```

Release binaries keep the same file names.
To download them from the new [releases page](https://github.com/dbccompany/terragrunt-atlantis-config/releases), change `transcend-io` to `dbccompany` in your download URLs.
